#Data

The datasets are intentionally excluded from this repository.

Add these course-provided files here before running the scripts:

- `text_feature_vectors.npy` — 400 BERT feature vectors with 1,024 features each
- `raw_text_reviews.txt` — the corresponding movie reviews (optional for the embedding plot)
- `breastmnist.npz` — BreastMNIST training, validation, and test arrays

The mammogram data originates from the [MedMNIST](https://medmnist.com/) collection. Check its current license and citation instructions before redistributing any data.
